                        🐛 TROUBLESHOOTING
================================================================================

Server not running?
  Terminal 1: php artisan serve
  Terminal 2: npm run dev

Database error?
  php artisan migrate:fresh --seed

Styles not loading?
  Make sure Vite dev server is running
  Hard refresh: Ctrl+Shift+R

"Ziggy error"?
  Use correct URL: /order/T01/menu (not /order/menu)
